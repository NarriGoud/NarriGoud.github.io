Overview

A computer vision project applying convolutional neural networks to identify plant diseases from leaf images — the kind of early-detection tool that can help reduce crop loss.

What I built

  • A CNN-based classification model trained on labeled leaf-image data.
  • An image preprocessing and data augmentation pipeline to improve generalization.
  • Feature extraction and model evaluation using TensorFlow and Keras.
  • A real-time prediction workflow deployed through Jupyter Notebook.
